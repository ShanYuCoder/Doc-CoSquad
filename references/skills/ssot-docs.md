# Skill: `/ssot-docs`

## Name
`docs-hub`

## Usage (Command/Trigger)
- Call via slash command: `/ssot-docs <command>`
- Used to manage and render documentation hub portals.

## Input
- Documentation hub root directory.

## Output
- Rendered Markdown artifacts, VitePress build outputs, and navigation sidebars.

## Description
- Manages local documentation rendering and live hosting servers.
- Synchronizes IR specifications into human-readable Markdown documentation.

---

## Example Prompt

```text
/ssot-docs render
```
